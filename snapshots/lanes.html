Arrange ​

Arrange is the song grid for stored snapshots: 4–256 rows of time (default 16) × 10 columns (Knobs, S32 LFOs, Rack 1–8). When the playhead lands on a row it recalls every occupied cell in that row (a scene). Empty cells are rest (--) and skip that bank. It is not a Step Seq MIDI device and does not sit in a rack.

Open ARRANGE from Main Menu — it is the first item, above Racks. The hub opens on the Knobs column. Rack, LFO, and snapshot grid nested menus do not have an Arrange shortcut.

The header title is ARRANGE (no timeline icon). Folder tabs SONG and a pencil sit left of the BPM band (never in it). The selected tab is a black tab with a thin outline that opens into the grid; the other one is plain gray text. The pencil is SETTINGS — the header never writes SETTINGS or SET. Two small gray squares with a dotted line under them, between the tabs and the BPM, mean Select + Back switches tabs. Hold Select for a moment on SONG and those squares become a bright circle and square (hold Select and turn to pick a column). A tap that never reached that hold still opens the cell picker; letting go after the column corners are showing does not. The BPM metronome in the header animates with the project clock.

SONG tab ​

All ten columns are on one page: K L R1 R2 R3 R4 R5 R6 R7 R8. Four song rows are visible; longer songs scroll so the focused cell stays in view. Occupied cells show two-digit slot ids 01–32. Rest cells show a dim --. Row numbers on the left are three digits 001–256. The cursor is four small corner marks at the focused cell. While the song plays, the playing row has its number on a gray block, and its occupied cells read brighter. When the clock is stopped or ARRANGE is OFF, no row is marked. A QUEUE-armed row's number block breathes (dims and brightens once per beat) until it fires or you cancel. A morphing bank’s column header is K* / L* / R1*…R8*. Column names are a legend (not an encoder stop).

Pencil tab ​

A full-width list with the same 13 px rows as other parameter lists (four visible; encoder scrolls): ARRANGE, RATE, FADE TIME, REPEAT, LENGTH, JUMP TO, QUEUE. Encoder moves between rows. The selected row is white text with the same corner marks as SONG. Hold Select makes the corners brighter and draws a line under the value, as wide as the longest value that row can show, so it does not move while you turn. Short Select on RATE, FADE TIME, REPEAT, or LENGTH latches sticky edit (a second set of corners inside the first, plus the same line; turn without holding Select). Tap Select again to keep the value; Back restores it — including the SONG / JUMP TO row if you had shortened LENGTH. Turn the encoder while holding Select to edit ARRANGE / RATE / FADE TIME / REPEAT / LENGTH, or to pick the SONG-focused row on JUMP TO (001–LENGTH, the same cursor as SONG). ARRANGE ON/OFF, REPEAT, RATE, FADE TIME, and LENGTH stop at the ends — they do not wrap. Hold Select on QUEUE does nothing. Select+Back returns to SONG. Back leaves Arrange (it does not return to SONG) unless sticky edit is open, in which case Back restores first. Encoder click is Clock Start/Stop.

Changing Rate while the arrangement is running keeps the current song row and the time already spent on it. If the new rate is longer (or shorter but you have not used up the new length yet), the row continues from those ticks. If the new rate is shorter and you are already past it, the playhead waits for the next bar, then moves once. Arrange Fade Time is only how the playhead glides in — pad / MIDI / SNAPSHOT macro glides use each bank’s own FADE TIME. It does not move the playhead.

Arrange (the first pencil-tab row) is whether the arrangement runs. ON (default) lets the playhead, Jump To, and Queue recall snapshots. OFF freezes the playhead and ignores Jump / Queue; the SONG grid stays editable. Select tap toggles ON/OFF. Turning the encoder while holding Select moves toward ON or OFF and stops at the end — it does not wrap. Old projects load as ON.

Rate is how long each row lasts against the project clock (24 PPQN):

Old projects that stored 1/8 or 1/4 load as 1 BAR. Start fires row 0 immediately at every Rate. Rate is how long until the next row. Transport Start resets the playhead; Continue keeps it.

Repeat is LOOP (wrap after the last filled row inside the current length) or ONCE (play to that row and stop).

Length is how many song rows are active (4–256, default 16). Hold Select + encoder. Shrinking the song does not erase hidden rows — lengthen again and they are still there. Jump, Queue, and the playhead stay inside the current length.

Jump To fires the focused song row now (instant — bypasses Fade Time) and cancels Queue. Queue arms or cancels that same row for the next Rate boundary (also instant versus a playhead fade). Both are a single Select tap. They do nothing while ARRANGE is OFF. Queue reads ARMED or OFF, never a second row number. While Queue is ARMED, a small bar before that word breathes on the pencil tab (and the armed SONG row's number block breathes). Jump To snaps an in-progress fade to its target; Queue cancels the fade without snapping. Queue still works after ONCE has already stopped.

When a row fires:

  • Rest (--) or an empty slot — that column is skipped.
  • Occupied slot different from the one already active — recall that snapshot (playhead uses Fade Time; Jump To and Queue are instant). While a glide runs on that bank, “active” is the pad it is gliding to. Any other occupied pad turns the glide toward that pad, starting from the live sound. That includes the pad the glide is leaving.
  • Same slot as now — no second recall.
  • A MORPH knob turned up on that bank does not hold the column back. The step takes over like a pad recall, and the knob picks up from the new percent. It reads 0% once the step lands.
  • Other columns in the row still fire.

Arrange edits and recalls do not force a flash save. Use Save Project so the pattern survives power-off.

Hold Select for a moment (not a tap) on SONG: the header mark becomes a circle and square, bright corners mark the whole current column (the cell corners go away), and the other columns dim before you turn. Letting go then does not open the cell picker.
