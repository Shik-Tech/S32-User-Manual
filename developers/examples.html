Examples ​

Each block runs as written in one s32 --loopback repl. On an S32, start s32 --usb repl instead.

Back up and restore a project ​

text
s32> list
s32> pull internal 1 /tmp/p1.s32p
s32> push /tmp/p1.s32p
s32> push /tmp/p1.s32p --activate
s32> active

See Push.

Map a knob to filter cutoff ​

Knob 05, macro 2, CC 74 on channel 3:

text
s32> macro set 4 1 mode=cc msb=74 channel=3
s32> potname set 4 Cutoff
s32> macro get 4 1

See Macros for every mode.

Add an Arpeggiator ​

text
s32> device add 0 arp
s32> device list 0
s32> device param set 0 1 rate 6
s32> device param get 0 1 rate

Sweep the Arpeggiator gate with an LFO ​

Continue from the block above. rack= and device= are ids, not positions:

text
s32> lfo cfg set s32 0 wave=triangle freq=0.5 enabled=on
s32> lfo assign add 0 target=device rack=100 device=1 param=gate min=20 max=80
s32> lfo assign add 0 target=lfo targetLfo=1 param=amplitude min=0 max=1
s32> lfo assign add 0 target=macro pot=2 macro=1
s32> lfo assign list

LFO 1 now also moves LFO 2's amplitude and knob 03, macro 2.

Grab the screen ​

text
s32> view nav s32-lfo index=2
s32> screen png /tmp/oled.png

Watch the knobs ​

bash
s32 --usb watch 8000

Prints knob events for eight seconds.

Build a song in Arrange ​

text
s32> snapshot store knobs next Verse
s32> snapshot store knobs next Chorus
s32> snapshot arrange set repeat=loop rate=4 length=16 knobs=0,1,0,1
s32> snapshot arrange get

New projects start with ARRANGE off, and USB writes the song but not that switch. Turn ARRANGE on in the pencil tab on the panel to start the playhead.

See Arrange.
