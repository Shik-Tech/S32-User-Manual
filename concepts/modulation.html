Modulation ​

INFO

Modulation here means LFOs (low-frequency oscillators) changing values over time — not knob macro setup (see Mapping) and not external MIDI learn (see External mapping).

The S32 has 16 LFOs. Each can drive multiple targets in the active project.

LFO → device parameter ​

Route an LFO to any rack device parameter (filter cutoff, arp rate, delay time, …):

  1. Open the device parameter list (rack grid → device).
  2. Highlight the parameter row.
  3. Hold Select (long press) Long-press Select → Options → Modulation → Assign LFO → pick the source LFO.

Options opens on the right half, titled with the parameter name. The row you opened it from stays readable on the left, so you can see which parameter the panel belongs to. Modulation carries the parameter's own mark — the LFO wave and number, the knob and macro, or the external CC — when something already drives it. Modulation and Mapping show >: they open a further list. In Snapshot and Allow Morph show their setting on the right; Select switches it.

One LFO can modulate many parameters. Assigned rows show an LFO mark (a small wave and the LFO number) before the value. It turns dim gray while that LFO is off:

INFO

Each project has a hard limit of 64 LFO assignments (one slot per distinct target). Changing the source LFO or range on an already-assigned target still works when the table is full; adding a brand-new target shows LFO ASSIGNMENTS FULL (64 MAX).

Remove LFO modulation ​

Hold Select (long press) Long-press Select on the assigned row → Options → Modulation → Remove LFO.

Set the modulation range ​

Every assignment sweeps its target over a window. Once an LFO is assigned, Range leads Options → Modulation; open it for Range Min and Range Max — for example 20% to 90%. The assign row now reads Re-Assign LFO.

  1. Highlight Range Min or Range Max.
  2. Hold Press Select (short) Select and Turn the encoder turn the encoder to widen or narrow that end. Release Select to keep it.
  3. Or tap Press Select (short) Select once to latch the edit, turn the encoder one-handed, then tap Select again to keep it. Press Back (short) Back puts the window back the way it was.

The endpoints follow the target: percent for Depth, signed percent for Offset, degrees for Phase, Hz or a note value for Rate, and the device's own unit for a device parameter. A window set from the computer editor appears here the same way. A new assignment still starts at the target's full range; a macro route starts at its default half-range window (see below).

Set Range Min above Range Max (or Range Max below Range Min) to run the sweep inverted on an S32 target: it moves the other way through the same window. The rows show it that way — Range Min above Range Max — with no separate marker. Re-Assign LFO resets the row to the target's full range but keeps the direction, so an inverted route stays inverted. Turn an endpoint back across the other one to sweep the normal way again. A CV16 LFO-to-LFO target always sweeps from the lower value to the higher one, so keep Range Min below Range Max there.

LFO → LFO parameter ​

An LFO can modulate another LFO’s parameters (rate, depth, phase, …) within the same domain (S32 LFOs or CV16 LFOs — not cross-domain).

  1. Main Menu → S32 LFOs → select the target LFO → open its editor.
  2. Highlight the parameter row (e.g. Rate).
  3. Hold Select (long press) Long-press Select → Options → Modulation → Assign LFO → pick the source LFO.

The assigned row shows the same LFO mark. Remove it with Options → Modulation → Remove LFO (same as device parameters).

INFO

More examples and loop rules: LFOs — LFO-to-LFO.

Loop prevention ​

WARNING

The firmware blocks assignments that would close a cycle in the LFO graph (self-modulation, A→B→A, longer loops). Fan-out (one LFO → many targets) is fine; routing back to an upstream LFO is not.

INFO

Knob → LFO via macro mode S32 LFO Parameter is configured under Mapping — it does not use the LFO assignment graph.

LFO → macro (MIDI message) ​

For MIDI message macro modes (CC, program change, 14-bit CC, channel aftertouch, poly aftertouch, NRPN, RPN, pitch bend, SysEx), an LFO can modulate the macro output — the values the macro sends when you turn the knob (within the macro’s min/max range).

While that LFO is off, turning the knob still sends the MIDI message. When the LFO is on, the modulation sends the value and the knob does not send it as well.

INFO

Device parameter and S32 LFO parameter macro modes are mapping targets for the knob itself, not LFO-to-macro modulation slots.

Changing Mode to Disabled, Device Parameter, S32 LFO, CV16 LFO, or CV16 CTRL removes that Assign LFO. Changing among MIDI message modes (for example CC to NRPN) keeps it. Assign the LFO again if you come back to a MIDI message mode.

Assign from Perform ​

  1. Configure the macro (e.g. CC mode) — see Setting up macros.
  2. On Perform, enter edit mode and Turn the encoder select that macro row.
  3. Hold Select (long press) Long-press Select → Options → Modulation → Assign LFO → pick the source LFO.

Set the macro modulation window ​

A macro assignment is a window around the knob, not a fixed Min / Max. Open Range under the macro row’s Options → Modulation to set Below and Above: how far the LFO moves the macro at the bottom and at the top of its wave, as a share of the macro’s own range. The knob position stays the base you play.

The values use the macro’s unit — a CC value, a 14-bit value, or a signed pitch-bend value. Half the range each way — Below -64 and Above +64 on a CC macro — is the default for a new assignment and keeps the LFO moving the macro around the knob. Set Below to 0 for a swell that only rises above the knob, or Above to 0 for one that only falls. Below above Above runs the window the other way. Re-Assign LFO puts the default window back but keeps that direction.

One click of the encoder moves the value by one step of the macro’s own range: one CC step on a CC macro, and one step on a narrow 14-bit range; a wide 14-bit range moves 128 per click.

A macro window never leaves the macro’s own Min / Max: near an end of the macro range the side that would pass it stays at the end.

When a modulator is assigned, the macro row shows the LFO mark — a small wave and the LFO number (~1) — just right of the bar, and the bar shows a dim line for the modulated level:

The menu is titled Macro N - Options for the selected macro (1-based). Assign LFO, Edit LFO, Enable/Disable, and Remove LFO live under Modulation, like device and LFO parameter Options. Remove LFO and Disable LFO ask for confirmation first (including the LFO and macro numbers); enabling an LFO applies immediately.
