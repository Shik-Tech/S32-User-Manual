Midi OUT

Send MIDI to a port

When to use it ​

Send processed MIDI to a hardware module, DAW, or another controller.

TIP

Place MIDI Out at the end of a rack (or before a final monitor tap).

Parameters ​

ParameterRangeWhat it does
Bypass0 – 1When on, the device is disabled and MIDI passes through unchanged.
Midi Port0 – 7Selects which physical or virtual MIDI interface this device uses.

Parameter values ​

Bypass ​

ValueNameMeaning
0OffDevice is active and processes MIDI.
1OnDevice is bypassed; messages pass through unchanged.

Midi Port ​

ValueNameMeaning
0USBDevice port on the USB device connection.
1Out 1DIN MIDI output 1.
2Out 2DIN MIDI output 2.
3USB HostClass-compliant device on the USB host port.
4Virtual AInternal virtual bus A.
5Virtual BInternal virtual bus B.
6Virtual CInternal virtual bus C.
7Virtual DInternal virtual bus D.
