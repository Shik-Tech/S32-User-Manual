Projects List ​

Main Menu → Projects → Projects List shows every saved project plus a New Project row at the top.

Rows use fixed right-side columns:

IconMeaning
SD cardProject is stored on microSD
CheckmarkActive (loaded) project
PlusCreate a New Project
Load arrowSelect loads that project
FloppySave Project (Projects menu only)

Internal-flash projects leave the SD column blank so icons align vertically across rows.

Browse and load ​

ControlAction
Turn the encoder EncoderMove between rows
Press Select (short) SelectLoad the highlighted project (may prompt if current project has unsaved changes)
Press Back (short) BackReturn to Projects menu

The list grows as you add projects — there is no fixed number of slots.

Create a project ​

  1. Highlight New Project (top row).
  2. Press Select (short) Select.
  3. Choose storage (Internal / microSD) when a card is present and formatted.
  4. Choose a project type:

TypeMacros
EmptyAll macros off (disabled) — knobs still have default names
DAW DefaultsMacro 1 on each knob sends CC (knob number); macros 2–4 stay off
  1. Confirm Create "Project N"?
  2. The new project becomes active. Configure racks and macros, then Save Project from the Projects menu.

Side menu (per-project actions) ​

On any existing project row (not + New Project):

  1. Hold Select (long press) Press Back (short) Hold Select + Back to open the side menu.

ActionWhat it does
RenameChange that project's name
Save AsCopy the project under a new name (editor opens with "<name> cp" — edit before confirming)
DeleteRemove the project after confirmation

Save As replaces the old Duplicate workflow: fork a variation, edit the name, then save.

If you see an error while creating, saving, or loading, see Troubleshooting.
