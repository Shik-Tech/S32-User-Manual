View, screen, events ​

bash
s32 --loopback view state
s32 --loopback view nav racks
s32 --loopback view index 2
s32 --loopback view back
s32 --loopback screen png /tmp/oled.png
s32 --loopback watch 2000

View ​

CommandWhat it does
view stateThe screen, highlighted row, Back depth and context (rack, device, knob, macro, bank)
view nav MENU [RACK [DEVICE]] [index=N] [part=PART]Opens a screen. RACK and DEVICE pick the rack and device it shows. index=N highlights row N (from 0). part= picks a snapshot bank
view index NMoves the highlight
view backLike pressing Back once

view nav replaces the current screen without adding a Back step. Back from there goes to Perform. A row number past the end is an error and the screen stays.

bash
s32 --loopback view nav perform
s32 --loopback view nav s32-lfo index=2
s32 --loopback view nav device-params 0 1

view nav device-params 0 1 opens rack 1, device 2. index= is the row, never the LFO, rack or device.

Screens view nav opens:

perform, main, settings, project-settings, clock, midi-settings, global-channel, middle-c, encoder-button, racks, devices, device, device-params, lfos, s32-lfo, cv16, cv16-lfos, cv16-lfo, projects, project-list, project-racks, snapshots, snapshot-parts, snapshot-racks, usb

Other screens (Arrange, editors, text entry) stay on the panel. Rename, add devices or load projects with their own commands (rack rename, device add, project load, …).

Screen ​

screen png FILE.png saves what the screen shows as a PNG.

Events ​

watch [MS] prints events for MS milliseconds (default 5000), including any queued by earlier commands in the same run. On --usb, turn a knob while it runs to see it.
