Envelope

ADSR envelope on MIDI

When to use it ​

Place Envelope when a CC, pitch bend, or other MIDI destination should follow an ADSR shape triggered by notes or a fixed key.

INFO

Sync sets the time unit for Attack, Hold, Decay, and Release.

SYNCED (default) follows MIDI Clock. Times show as note values (1/16, 1/8, 1/4, 1/2, 1/1, 2 BARS, …). Any other time shows a number with T.

FREE uses milliseconds and runs with no MIDI Clock.

Release ​

After you let go, the note stays on while the destination fades. The note ends when Release finishes. If the transport stops before that, the note ends then. Release 0 ends the note right away.

Mono does this when the last note of a chord goes up. Poly fades each note on its own. Key does this only for Key Note. Loop ends the note as soon as you let go.

Dest ​

On the device the list is CC, Pitch Bend, Ch. Pressure, Poly AT (only when Trigger is Poly), CC 14-bit, NRPN, RPN, then Prog. Change.

With Poly and Poly AT, each held note sends its own pressure. Any other destination sends one message that follows the held note with the highest level.
