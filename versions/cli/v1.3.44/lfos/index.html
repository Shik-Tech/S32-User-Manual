S32 LFOs ​

The S32 has 16 LFOs. Each one can move device parameters, other LFOs and MIDI macros: see Modulation.

LFO grid ​

Open Main Menu → S32 LFOS. Four LFOs per page, four pages.

Press Select (short) Select opens the LFO. Hold Hold Select (long press) Select for its menu:
RowWhat it does
REVIEW ASSIGNMENTSLists everything this LFO moves
SNAPSHOTS BANKOpens the LFO snapshots
IN SNAPSHOTOFF keeps this LFO as it is on every snapshot recall. See Snapshots

In REVIEW ASSIGNMENTS, select a Step Seq step or Euclid layer row to open that step or layer.

Edit an LFO ​

ParameterWhat it does
ENABLEDON runs the LFO. OFF stops it moving every target it's assigned to
WAVETABLEThe shape: SINE, TRIANGLE, SQUARE, SAWTOOTH, FOLD, S&H, EXP., STEPPED, DOUBLE SINE, REV SAW, BELL, DOUBLE TRI, SMOOTH RND, TRAPEZOID, PUMP, ROUND SQ, HALF SINE
PHASEWhere in the cycle the wave starts
OFFSETShifts the whole wave up or down
RATESpeed: a note value with SYNC on, Hz with it off
SYNCON locks the rate to the project tempo
DEPTHHow far the wave moves its targets

To change a value: Edit a value.

Move an LFO with another LFO ​

One LFO can move another LFO's settings, for slow sweeps of rate or depth: see Modulate another LFO.

To move an LFO setting with a knob instead, use an S32 LFO macro.
