LFO parameter macro rows ​

An S32 LFO or CV16 LFO macro lets the knob play an LFO: speed it up, deepen it, move where its wave starts. The LFO keeps moving whatever it's assigned to.

The row reads the LFO (L1–L16), the setting and its value: L1 RATE 1/4.

  • S32 LFO sets one of the project's LFOs.
  • CV16 LFO sets an LFO on a connected CV16.

The knob changes the LFO's own setting, the same as editing it on the LFO's page. SAVE PROJECT keeps it, and a morph back to 0% returns to it.

This is the opposite of an LFO moving a macro, which shows as ~1 on a classic MIDI row.

Set these macros up: S32 LFO · CV16 LFO.
