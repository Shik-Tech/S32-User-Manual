Device parameter macro rows ​

A DEVICE macro turns the knob into a control for a device in one of your racks: the arpeggiator's gate, Seed's density, a Scaler's scale. It sends no MIDI itself; the device plays the result.

The row reads rack, device, parameter, then the value in the device's own units: 01 GENERATIVE ARP GATE 72%. A rack with no name shows as RACK 1–RACK 8.

The knob changes the device's own setting, the same as editing it on the device's page. On that page, the parameter shows a badge with the knob number. Delete the device and the row reads SET TARGET.

Rack BYPASS ​

A rack's BYPASS is a whole-rack switch, not a device parameter: its row reads the rack name and BYPASS, with ON or OFF on the right and a two-sided switch bar. The knob bypasses the rack from the middle up. A RACK CTRL macro with no rack set reads SET TARGET.

Set it up from the rack menu, or pick RACK CTRL in the macro's MODE: RACK CTRL.

Set these macros up: DEVICE macro.
