Use the S32 with AI ​

An AI agent can build racks, map knobs and set up LFOs on your S32 while you play. You say what you want in plain words. The agent runs the commands, shows you what it will change, and checks the result.

It needs an agent that can run commands on your computer. A chat-only app can read these pages, but it cannot reach your S32.

In three steps ​

  1. Set up your agent. Paste one block into your agent. It installs the s32 CLI, checks the link to your S32 and saves the s32-cli skill with the rules it follows.
  2. Try a prompt. Start with a quick starter: ask what is on your S32, arpeggiate your keyboard, or put a filter cutoff on a knob.
  3. Change safely. The agent reads first, previews, asks you, changes, then checks. A few commands that change a lot at once always ask for your yes.

Close the web editor while an agent works: the S32 talks to one app at a time.

Agents that read this manual find an index of its pages in For agents. Prefer to type the commands yourself? See the s32 CLI.
