Modulation ​

Let an S32 LFO move things for you: a filter that breathes, an arpeggio whose gate drifts, a CC that swells. One LFO can move many targets.

TargetWhere you assign it
A device parameterHold Hold Select (long press) Select on the parameter → MODULATION → ASSIGN LFO
A rack's BYPASSRACKS → hold Select on the rack → hold Select on BYPASS → MODULATION → ASSIGN LFO
Another LFO's parameterThe same, in the LFO editor
A MIDI macroHold Select on the macro row in edit mode → MODULATION → ASSIGN LFO

Modulate a device parameter ​

  1. Open the device from its rack and go to the parameter.
  2. Hold Hold Select (long press) Select.
  3. Choose MODULATION → ASSIGN LFO and pick the LFO.

On an assigned parameter, MODULATION offers:

RowWhat it does
RANGEHow far the LFO sweeps (below)
RE-ASSIGN LFOSwaps in another LFO
EDIT LFOOpens the LFO's settings
DISABLE LFO / ENABLE LFOSwitches the whole LFO off or on, for every target it moves
REMOVE LFORemoves this route only

A project holds up to 64 LFO routes. Past that, a new one shows LFO ASSIGNMENTS FULL (64 MAX).

Set the range ​

RANGE MIN and RANGE MAX set where the sweep starts and ends, in the parameter's own unit. A new route sweeps the whole range.

To change them: Edit a value. Set RANGE MIN above RANGE MAX to sweep the other way. RE-ASSIGN LFO resets the range but keeps the direction.

Modulate another LFO ​

Slow sweeps of another LFO's rate or depth, or switching it on and off:

  1. Open the LFO you want to move in S32 LFOs and go to the parameter (RATE, say).
  2. Hold Hold Select (long press) Select → MODULATION → ASSIGN LFO.
  3. Pick the LFO that does the moving.

Choose ENABLED to switch the other LFO on and off: above the middle of the range it runs, below it stops. Removing the row, or moving it to another target, leaves the LFO where the modulation left it. Its own ENABLED setting applies again on the next project load or snapshot recall.

An LFO can't feed itself, directly or around a loop (1 → 2 → 1, or 1 → 2 → 3 → 1), so it can't switch itself off.

Modulate a MIDI macro ​

An LFO can move a knob's MIDI macro (CC, 14-bit CC, Program Change, NRPN, RPN, pitch bend, aftertouch or SysEx). The knob sets the centre; the LFO moves around it.

  1. In edit mode, go to the macro row.
  2. Hold Hold Select (long press) Select.
  3. Choose MODULATION → ASSIGN LFO and pick the LFO.

MODULATION → RANGE sets BELOW and ABOVE: how far the LFO reaches under and over the knob. A new route reaches half the macro's range each way (BELOW -64, ABOVE +64 on a CC). Set BELOW to 0 for a swell that only rises, or ABOVE to 0 for one that only dips. The sweep stays inside the macro's MINIMUM and MAXIMUM.

Switch the LFO off and the knob sends as usual.

Changing the macro to a mode that isn't MIDI (DEVICE, S32 LFO or DISABLED) removes its LFO. Switching between MIDI modes keeps it.
