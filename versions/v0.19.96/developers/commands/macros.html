Macros and knobs ​

Each of the 32 knobs has four macros. A macro turns knob motion into MIDI, a rack device parameter, an S32 LFO parameter or a CV16 output.

bash
s32 --loopback macro get 4 1
s32 --loopback macro set 4 1 mode=cc msb=74 channel=3
s32 --loopback potname get 4
s32 --loopback potname set 4 Cutoff
s32 --loopback knobmap get 0
s32 --loopback knobmap copy 3 9

macro get / macro set ​

macro get KNOB MACRO: knob 0–31, macro 0–3.

macro set KNOB MACRO key=value … changes only the keys you name:

KeyValues
modeA name from the table above
msbCC number, program number, NRPN/RPN MSB, note, …
lsbLSB, where the mode has one
channelglobal or 1–16
min / maxRange. 7-bit modes: 0–127. cc14, nrpn, rpn, pitch-bend, sysex: 0–16383
inverton / off
outputsnone, usb, out1, out2, or a + mix such as usb+out1
pickupon / off
inIN SNAPSHOT, on / off
rack / device / parammode=device: rack and device ids from rack list / device list, and a parameter name (bypass, rate, gate, …) or number from schema
submode=device on a Step Seq step: the step, 0–15
lfo / cvParammode=s32-lfo and cv16-lfo: the LFO (from 0) and its parameter (rate, amplitude, depth, …)
cvmode=cv16: the output, 0–15
nameThe label for a named control
text
macro set 4 1 mode=cc msb=74 channel=3 outputs=usb+out1
macro set 0 2 mode=cc14 msb=1 lsb=33 channel=3
macro set 0 0 mode=device rack=100 device=1000 param=bypass
macro set 2 0 mode=s32-lfo lfo=0 cvParam=amplitude
macro set 3 0 mode=disabled

Switching into cc14, nrpn, rpn, pitch-bend or sysex without min=/max= sets the full 0–16383, as on the panel. For any other mode change, name min= and max= on the same line.

target=snapshot-slot and target=morph-amount with part= turn a macro into a snapshot picker or a morph knob. See Snapshots.

Knob names ​

potname get KNOB and potname set KNOB NAME.

Knob map ​

knobmap get [START] lists knob names and their macros from START.

knobmap copy SRC DST copies one knob's name and all four macros onto another.
