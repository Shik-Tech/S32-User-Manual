External MIDI map ​

Incoming CC on a channel, mapped to an S32 parameter.

CommandWhat it does
extmap listEvery row
extmap add CH CCAdds a row for that channel (1–16) and CC
extmap set INDEX CH CCRewrites that row in place
extmap remove INDEXDeletes that row

target=snapshot-slot or target=morph-amount with part= makes the CC pick a snapshot or drive a morph. See Snapshots.

Project meta ​

meta get prints the project's BPM, clock mode, channel, encoder button action, tags and description. meta set BPM DESCRIPTION writes the BPM and description and keeps the tags.

Globals ​

KeyValuesWhere it lives
clockModeinternal, external, autoProject
bpmInternal clock BPMProject
globalChannel1–16Project
encoderBtnclock, racks, lfosProject
transportstopped, runningLive only
midiThruon, offS32
contrast0–255S32

Project values change the project you are playing. SAVE PROJECT (or project save) keeps them. globals get also prints defaultVolume, which s32 can't change.
