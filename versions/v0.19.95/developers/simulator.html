Simulator and scripts ​

--loopback ​

--loopback runs the same protocol against a simulated S32 inside the s32 process. No hardware needed. Use it to try commands, write examples and run CI.

  • Every run starts fresh with three projects (Project 1–3) and one card project. A macro set in one run is gone in the next. Chain steps in a REPL or a script.
  • Sample device types. The simulator knows a few devices. For the real list, run schema --emit-schema-json over --usb.

--script ​

One command per line. # starts a comment. Nothing asks for confirmation. The run stops at the first line that fails and exits non-zero. pause [MS] waits (default 1000 ms).

bash
s32 --loopback --script session.script
s32 --usb --script session.script

session.script:

text
hello
list
macro get 0 0
macro set 4 1 mode=cc msb=74 channel=3
potname set 4 Cutoff

Words in a script line split on spaces, with no quoting. Use names without spaces.
