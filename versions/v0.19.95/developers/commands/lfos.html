LFOs ​

text
s32 --loopback repl
s32> lfo cfg get s32 2
s32> lfo cfg set s32 2 wave=sine freq=3.75 enabled=on
s32> lfo assign add 2 target=macro pot=4 macro=1 min=-0.25 max=0.25
s32> lfo assign list
s32> lfo assign remove 0

DOMAIN is s32 (the S32's own LFOs) or cv16 (the CV16 module's). INDEX is the LFO, 0–15.

Settings ​

lfo cfg get DOMAIN INDEX prints the LFO's settings, then its IN SNAPSHOT (liveOwned=) and ALLOW MORPH (allowMorph=) bits as hex masks. lfo cfg set never changes those bits. Use snapshot flags and snapshot parent.

lfo cfg set DOMAIN INDEX HZ sets the frequency and turns the LFO on.

lfo cfg set DOMAIN INDEX key=value … changes only the keys you name. Values outside the LFO's range are refused.

Assignments ​

lfo assign add LFO target=… … adds a row. lfo assign set ROW LFO target=… … rewrites one. lfo assign remove ROW deletes one. lfo assign list shows the row numbers.

target=MovesAddressparam=
deviceA rack device parameterrack=ID device=ID (ids from rack list / device list)Parameter name (bypass, rate, gate, …) or number
lfoAnother LFO in the same domaintargetLfo=INDEXLFO parameter (amplitude, frequency, phase, …)
macroA knob macropot=KNOB macro=MACRO—

An LFO can't modulate itself, an LFO in the other domain, or close a loop of LFOs (1 → 2 → 1). Those rows are refused.

Range ​

For device and lfo targets, min and max are values in the target's own range. Values outside it are clamped to the edge. On S32 targets min above max runs the sweep the other way. A CV16 LFO-to-LFO row refuses that.

For macro targets, min and max are the BELOW and ABOVE window around the knob, as fractions of the macro's range from -1 to 1. The default is -0.5 / 0.5. min=0 max=0.4 only rises above the knob. Capability bit 1024 in hello means the firmware uses this window.
