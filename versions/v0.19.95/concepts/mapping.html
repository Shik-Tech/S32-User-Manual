Mapping ​

Mapping connects a control to something the S32 does.

SourceWhat it drivesSet it up
A knob (macro)MIDI out, a device or LFO parameter, a snapshot, a morphSetting up macros
Incoming MIDIA device or LFO parameter, or a snapshot bankMap incoming MIDI
An LFOA device or LFO parameter, or a MIDI macroModulation

Knob macros ​

Each of the 32 knobs has four macros, rows 1–4 in edit mode. One knob can send a CC, turn a filter on a rack device and change an LFO rate at the same time.

A macro can:

  • send MIDI: CC, 14-bit CC, Program Change, NRPN, RPN, pitch bend, aftertouch or SysEx;
  • turn a rack device parameter;
  • turn an S32 LFO or CV16 LFO parameter;
  • send control voltage from a CV16 jack;
  • pick a snapshot or set a morph.

Every mode: Macro reference.

Map a knob from the parameter ​

  1. In a device or LFO parameter list, hold Hold Select (long press) Select on the parameter.
  2. Choose MAPPING → INTERNAL MAPPING.
  3. Pick the knob (06 Cutoff), then the macro.

On a mapped parameter, INTERNAL MAPPING offers MAP PARAMETER (replace) and REMOVE MAPPING.

Map incoming MIDI ​

Play device and LFO parameters from another controller or a keyboard.

  1. In a device or LFO parameter list, hold Hold Select (long press) Select on the parameter.
  2. Choose MAPPING → EXTERNAL MAPPING. The screen asks SEND A NOTE, CC, OR 14-BIT CC.
  3. Move the control on your other gear.

You sendIt does
CCSweeps the parameter from its lowest to its highest value
14-bit CCThe same, in finer steps
NoteVelocity sets the value. An on/off parameter flips on each note

It listens on the channel you learned, on any MIDI input. The mapped CC or note no longer reaches your racks.

To remove it, choose MAPPING → EXTERNAL MAPPING on that row again.

A parameter takes a knob or external MIDI, not both: to learn MIDI on one a knob turns, remove the knob first (MAPPING → INTERNAL MAPPING → REMOVE MAPPING). An LFO can still move it.

Program Change, notes or a CC can also pick a snapshot pad: see Map a knob or MIDI to scenes.

Parameter marks ​

A parameter row shows one mark:

MarkMeans
Small wave + numberAn LFO moves it. Dim while that LFO is off
Four bars + numberA knob turns it. The lit bar is the macro row
Arrow + CC or noteIncoming MIDI turns it

With more than one set, the row shows the LFO first, then the knob, then MIDI, and a dot at the top right. Hold Select on the row to see them all.
