Rack Chains ​

A rack is an ordered list of MIDI devices. MIDI enters at the start of the chain and exits at the end — like pedals on a floor or modules in a DAW chain.

Why chains matter ​

Each device transforms or routes MIDI:

  • Filters pass or block by channel, note range, CC type
  • Generative devices (Arpeggiator, Euclid, Seed, Step Seq) create new notes
  • Pitch devices (Scaler, Transpose, Harmony) reshape pitch
  • I/O devices connect to physical ports or clock

TIP

Order matters: a Channel Filter before an Arpeggiator behaves differently than after.

Building a chain ​

  1. Main Menu → Racks → pick a rack.
  2. The + card at the end of the chain opens the device picker (one category per page).
  3. Press Select (short) Select a device to open its parameter list (Step Seq opens a step grid; Euclid opens a GRID of layer rows).
  4. Hold Select (long press) Long-press Select on a device card to open Options. Move Device (when the device can slide) then turn the encoder to reorder; Select drops it, Back cancels. Holding Select while moving still drops — it does not reopen Options. MIDI IN stays first. MIDI OUT stays last. The header Select square fills while you hold for Options.

Parameter editing ​

Device parameters use the same list UI as LFOs:

  • Turn the encoder Encoder — move between rows, or change the value while sticky edit is latched
  • Press Select (short) Select — latch sticky edit on a value (tap again to keep it); on/off rows still toggle
  • Press Back (short) Back — while sticky, restore the value from when you entered and leave the list
  • Hold Select (long press) Long-press Select — Options → Modulation (Assign LFO), Mapping (Internal / External mapping), or IN SNAPSHOT (keep this one parameter out of every snapshot — see Snapshots)

INFO

See Device reference for every device type.

Multiple racks ​

Each project holds up to 8 racks. Route different MIDI streams through different chains (see Router and Dispatch devices).

Rack snapshots ​

Hold Select (long press) Long-press Select on a rack in the list opens Rename Rack, Duplicate Rack, Clear Rack, and Snapshots Bank. Snapshots Bank opens that rack's snapshot grid, where you take and recall snapshots for that rack only. An empty rack cannot be stored.

See Rack snapshots.

Devices in a chain ​

Each rack chain can hold up to 10 devices total. When you open the device picker, types you cannot add right now appear dimmed with 0 — the rack may be full, or you already have the maximum of that type. Highlight one and the bottom line says why.

Duplicate on a device side menu follows the same rules as adding from the picker.

Per-type maximums (one rack) ​

Device typeMax in one rack
Total devices10
MIDI Input / MIDI Output / Clock1 each
Scaler / Transpose / M2CV1 each
Euclid3
Other types (default)4 each

Category maximums ​

Device types in the same category share a cap when there is no per-type rule above:

CategoryMax per type in one rack
I/O & Clock1
Generative4
Pitch & Harmony4
Filters8
Routing4
Dynamics4
Effects4
Utility4

Per-type rules (for example, only one Clock) override the category default.

If the S32 refuses to add or duplicate a device, see Troubleshooting.
