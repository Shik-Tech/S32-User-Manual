On Euclid GRID, long-press Select opens that layer’s left parameter list (like Step Seq STEP). The header Select square fills on those SEQ / GRID holds the same way it does for Options.

Projects, Storage, and the MIDI device type picker stay Select + Back.

The header ​

Every screen has the same header. From left to right: page arrows (1/2) or a device icon, a dim number or path (01, R1/), the screen name, the knob map on Perform and the Knobs Grid, a counter such as 6/15, the folder tabs, a small mark that shows what the buttons do right now, and the BPM. The BPM is on every screen.

Mark (left of the BPM)Meaning
Two gray squares with a dotted lineSelect + Back switches the folder tabs
Bright circle and squareSelect is held: turn the encoder to edit the focused value
Circle and a square filling from the bottomA long press is arming; let go early to cancel
Floppy diskThe project is saving

Page arrows are bright when there is a page that way and dim at the ends.

Lists ​

Long menus show a scrollbar on the right. Turn the encoder Turn the encoder to move the highlight.

On a device or LFO parameter list (and on Step Seq SETTINGS / STEP lists, or Euclid LAYER / pencil lists), tap Press Select (short) Select on a value to latch edit, then turn the encoder with one hand. Sticky edit uses brighter nested L-corners on that line (not a filled row). The header Select square still fills only while you hold Select. Tap Select again to keep what you hear and stay on that list. Press Back (short) Back puts the value back where it was when you entered and leaves the list. Hold Select and turn to drag-edit instead — letting go keeps the value and does not stay latched. On/off rows still toggle on a Select tap.
