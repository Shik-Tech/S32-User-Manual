Device parameter macro rows ​

A device parameter macro turns the knob into a control for something inside your rack chain — arpeggiator gate, seed density, scale selection, and so on. The row shows which rack, which device, and which parameter you are affecting. It does not show MIDI channels or output ports because nothing is sent as a standalone MIDI message.

RowDeviceParameterExample in screenshot
0ArpGateArpeggiator gate length (32–96% range)
1Harmony1stFirst harmony interval
2SeedDensityHow many seed notes fire
3ScalerScaleWhich scale preset is active

Reading a device row ​

Rack (01, 02, …) ​

Which rack in the active project contains the target device. The number is two digits, 01–08.

With one macro, the device icon sits above that number and the full rack name. With two, the icon sits just before the number on the same line. With three or four macros there is no icon: the number and the first five letters of the rack name come first (01 GENER for GENERATIVE), then the device and the parameter. The number already tells the racks apart, so the rack name is the part that gets cut. A rack with no name reads RACK 1–RACK 8.

Device ​

The short device name, the same one the rack and the add-device list show: ARP, TRANSPO, VEL. AMP, NOTE RNG, CH FILT, CC TYPE, CC VAL, INPUT, OUTPUT, and names that are already short such as SEED, DISPATCH, and STEP SEQ. The device page header spells the full name (TRANSPOSE, NOTE RANGE FILTER, …).

Parameter ​

The field on that device the knob drives — Gate, Density, Scale, Rate, etc. Up to twelve letters fit. A longer name is cut at the end of its space, with no ....

These rows never show the ~ modulator mark: an LFO cannot ride a device-parameter macro. To move that parameter with an LFO, assign it on the device page (Options → Modulation → Assign LFO); the ~ mark then shows on the device page row.

Live value ​

Shown in the device’s own units: 100%, Custom, 0st, and so on. Min/max limits from edit mode apply here and on the matching indicator bar.

Elsewhere on screen ​

When a knob macro targets a device parameter, that parameter’s editor row can show a knob-macro badge (filled dots + knob number). To change or clear the mapping, use Perform → edit mode — not the device parameter list.
