Clock

BPM, transport, and clock output

When to use it ​

Use Clock when this rack should generate or forward MIDI clock and transport.

TIP

Put it first in clock-driven chains (Seed, Step Seq, Euclid, Arp, Looper) so downstream devices receive a steady tick.

Parameters ​

ParameterRangeWhat it does
Bypass0 – 1When on, the device is disabled and MIDI passes through unchanged.
Division0 – 8Clock output rate as a fraction of the master clock (1/1 … 1/24).

Parameter values ​

Bypass ​

ValueNameMeaning
0OffDevice is active and processes MIDI.
1OnDevice is bypassed; messages pass through unchanged.
