CC Type Filter

Pass or block CC types

When to use it ​

Use CC Type Filter to pass or block Control Change numbers in a CC range (by controller number, not value). Notes, clock, and other non-CC messages pass through unchanged.

Parameters ​

ParameterRangeWhat it does
Bypass0 – 1When on, the device is disabled and MIDI passes through unchanged.
RNG START0 – 127Low CC number of the window.
RNG END0 – 127High CC number of the window.

Parameter values ​

Bypass ​

ValueNameMeaning
0OffDevice is active and processes MIDI.
1OnDevice is bypassed; messages pass through unchanged.
