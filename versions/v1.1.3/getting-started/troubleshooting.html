Troubleshooting ​

Projects and storage ​

MessageWhat it meansWhat to try
STORAGE FULLNo room to save.Delete a project you no longer need (Library), or add a microSD card
FRAGMENTED - COMPACT ITFree space is in pieces too small for the save.In Storage Info, hold Select on INTERNAL and choose COMPACT STORAGE
PROJECT DIRECTORY FULLThe Library holds as many projects as it can.Delete a project you no longer need
SAVE FAILEDThe project could not be saved.Try SAVE PROJECT again. If it keeps failing, check Storage Info
USB TRANSFER IN PROGRESSA computer is copying a project to or from the S32.Wait for the copy to finish, then try again
PROJECT NEEDS OLDER FIRMWARE FIRST / PROJECT NEEDS NEWER FIRMWARE (at boot)The last open project can't be opened on this firmware.Install firmware that matches the project. SAVE PROJECT won't overwrite it
LOAD FAILED - PROJECT RESETThe project didn't finish loading.Load it again from the Library. It is untouched, and SAVE PROJECT won't overwrite it
SAVE BEFORE SWITCHING?The open project has unsaved changes.Confirm to save them first, or cancel to choose whether to discard them

Racks and devices ​

MessageWhat it meansWhat to try
THIS RACK IS FULL (10 DEVICES MAX)The rack holds 10 devices.Remove a device, or use another rack
A dimmed card in the device pickerThat device can't be added here.The line under the cards says why, for example ADD MIDI IN OR CLOCK TO AN EMPTY RACK FIRST
NOT ENOUGH MEMORYNo room to duplicate this rack.Remove devices from other racks, then try again
RACK n NEEDS MIDI IN OR CLOCK FIRSTThe rack's first device is neither MIDI IN nor CLOCK, so it does not play.Add MIDI IN or CLOCK; it goes to the top. See Start a rack
