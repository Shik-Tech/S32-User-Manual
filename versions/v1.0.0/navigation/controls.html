Controls ​

Do thisTo
Press Select (short) Press SelectOpen what's highlighted, or edit a value
Press Back (short) Press BackGo back one step
Hold Select (long press) Hold SelectOpen the side menu
Hold Back and Select together Hold Select + BackOpen the Main Menu, or switch tabs
Press the encoder Press the encoderStart or stop the clock

The encoder press can open Racks or LFOs instead: ENCODER BUTTON.

Edit a value ​

  1. Press Select (short) Press Select on the value.
  2. Turn the encoder Turn the encoder. The change takes effect as you turn.
  3. Press Select (short) Press Select or Press Back (short) Back to finish. The new value stays.

For a quick change, Hold Select (long press) hold Select, turn, and let go.

  • Turn slowly for single steps, faster to cover a wide range.
  • ON/OFF settings work the same way: turn to ON or OFF.
  • Values stop at their first and last setting; they don't wrap around.
  • Action rows, such as RECORD or RANDOMIZE, act on a single press.
  • A dimmed setting doesn't apply right now, such as KEY NOTE while the Envelope's TRIGGER isn't KEY. The encoder skips it and it keeps its value.

Side menus ​

Hold Select (long press) Hold Select on a row, card or pad to open its side menu, like right-clicking on a computer. It holds what you can do with that item: rename, duplicate, remove, Modulation, Mapping, IN SNAPSHOT.Press Select (short) Select picks a choice. Press Back (short) Back goes back one level, then closes the menu.

On Perform, holding Select opens edit mode instead.

Select + Back ​

Hold Back and Select together Hold Select + Back:
  • On Perform or the Knobs Grid: open the Main Menu.
  • On a screen with tabs: switch tabs.
  • Anywhere else: nothing.

Header marks ​

A small mark left of the BPM shows what the buttons do right now.

MarkMeans
Two squares over a dashed lineSelect + Back switches tabs here
Circle and squareSelect is held: turning changes the value
Square filling upKeep holding Select: the side menu (on Perform, edit mode) opens when it's full
FloppyThe project is saving
Warning triangleA MIDI output was full and skipped some new notes. See When an output is full
