Chance

Probabilistic note gate

When to use it ​

Drop notes at random to make a busy pattern breathe.

INFO

With RATE on a note value, put a Clock before it in the rack. RATE OFF works without one.

Parameters ​

ParameterRangeWhat it does
BYPASSOFF / ONON: MIDI passes through untouched. See BYPASS.
CHANCE0% – 100%How often a note passes.
RATEOFF – 1/64OFF decides each note. A note value makes one decision per period: every note in it passes or drops together.
USE VELOCITYOFF / ONON: each note's velocity sets its chance and CHANCE is ignored. Soft notes drop more often.
