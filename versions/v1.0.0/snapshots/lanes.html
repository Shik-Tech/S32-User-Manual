Arrange ​

Arrange plays your snapshots as a song. Each row is a step in time; each column is a bank: K (knobs), L (S32 LFOs) and R1–R8 (racks). When the playhead reaches a row, every filled cell in it recalls that pad.

Open ARRANGE from the Main Menu.

Hold Hold Back and Select together Select + Back to switch between SONG and the pencil tab (settings).

Write the song ​

  1. Go to a cell.
  2. Press Select (short) Select opens the picker: -- REST, then every stored snapshot on that bank (01 INTRO, 02 VERSE…).
  3. Choose one and press Select to place it.

To change column, hold Hold Select (long press) Select and turn.

  • -- is a rest: that bank keeps what it has.
  • A row number pulsing on the beat is armed with QUEUE.
  • K*, L* or R1*… in the header means that bank is in a morph.

Play it ​

Arrange follows the project clock. Start it with the encoder button (CLOCK START/STOP, the default) or from Clock Settings. With ARRANGE on, Start plays from row 001; Continue carries on from where it stopped.

A row that repeats the pad already playing on a bank doesn't recall it again. A row that lands while a MORPH knob is up on that bank takes over, and the knob picks up from the new percent.

Pencil tab ​

RowWhat it does
ARRANGEOFF (default). ON plays the song; OFF stops the playhead, JUMP TO and QUEUE. You can still write the song
RATEHow long each row lasts: 1 BAR to 128 BARS
FADE TIMEHow the playhead glides into each row: OFF (default), 1/16, 1/8, 1/4, 1/2, 1 BAR, 2 BARS, 4 BARS
REPEATLOOP goes back to the top after the last filled row. ONCE stops there
LENGTHHow many rows the song has: 4–256 (default 16). Rows beyond it are kept, not erased
JUMP TOPlays the chosen row now (ARRANGE ON)
QUEUEArms the chosen row for the next RATE step (ARRANGE ON). It reads ARMED; Select again cancels

To change a value: Edit a value. JUMP TO and QUEUE act on a press of Select, on the row under the SONG cursor. To pick another row from here, hold Select on JUMP TO and turn. Both land instantly, without FADE TIME. JUMP TO first finishes a fade that is running. QUEUE stops it where it is.

Arrange FADE TIME is for the playhead only. Pads, MIDI and snapshot knobs use the FADE TIME of their own bank.

Changing RATE while the song plays keeps the current row. If the row has already run longer than the new rate, the next row starts on the next bar.

Arrange edits last until power-off; SAVE PROJECT keeps them (Projects).
