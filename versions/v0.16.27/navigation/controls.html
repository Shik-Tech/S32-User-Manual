ChordContextResult

Perform (home) ​

ControlAction
Turn a panel knobShow that knob and send MIDI
Press Back (short) BackOpen Knobs Grid
Press Select (short) SelectEnter edit mode (Macro selection)
Turn the encoder EncoderNo knob browsing on Perform — use the Grid to pick by name

On the Grid: encoder highlights a knob; Select confirms; Back cancels (original pot). The overlay does not close on idle.
