Troubleshooting ​

What common on-screen messages mean and what to try next.

Projects and storage ​

MessageWhat it meansWhat to try
Storage fullAggregate free space is exhaustedDelete a project you no longer need, or check Storage Info
Fragmented - compact itFree space exists but is split into holes too small for the saveRun Compact Storage from Storage Info (Internal side menu)
Directory fullThe project list cannot grow further on this storage volumeDelete unused projects, or free space via Storage Info
Save failedThe S32 could not write your projectTry Save Project again; if it keeps failing, check Storage Info. After a failed New Project, Save Project still writes the project you were on, not the unsaved Empty or DAW Defaults set. A failed Rename of a microSD project leaves that card file in place
USB transfer in progressA computer is copying a project to or from the S32Wait until the copy finishes. The message clears on its own. You can save, load, or delete after that
Project needs older firmware first / Project needs newer firmware (at boot)The last project cannot be opened on this firmwareSave Project does not overwrite that slot. Install matching firmware to open it, or save the empty set as a new project
Load failed - project resetThe other project did not finish loadingIf the knobs went blank and no project has a checkmark, Save Project will not overwrite the project you were on — including a project on the microSD card. Load it again from Library, or use Save As for the empty set. If the knobs still show the previous project, that project is still in memory, including its snapshots.
Unsaved changesYou edited the current project but have not savedSave Project, discard, or cancel before switching away

Racks and devices ​

MessageWhat it meansWhat to try
This rack is full (10 devices max)The chain already has ten devicesRemove a device, or start a second rack in the same project
Device dimmed in the pickerThat type cannot be added right nowThe rack may be full, or you already have the maximum of that device type — see Rack chains
Not enough memoryThe S32 cannot duplicate or add this chain right nowRemove devices or use a simpler chain, then try again
