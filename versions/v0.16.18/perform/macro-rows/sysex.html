SysEx on Perform ​

SysEx macros send a custom MIDI System Exclusive message from the knob. On Perform they use the same row layout as other classic MIDI modes: SYX tag, byte indices, channel, output boxes, and a live value.

WARNING

This guide is not finished yet — screenshots and walkthrough for SysEx perform rows are coming soon.

Until then, build your message in edit mode with the SysEx macro grid and SysEx editor.

What to expect on the row (preview) ​

Part of rowSysEx macro
Message typeSYX
Byte indicesMSB/LSB — which bytes in your message the knob writes to
ChannelG or Ch1–Ch16
OutputsU / 1 / 2
Live value14-bit level mapped into those bytes
