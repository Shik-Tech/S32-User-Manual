Step Seq

Classic clock-synced step sequencer

When to use it ​

Add Step Seq after a Clock when you want a classic 4–16 step sequencer you edit on a full-screen grid — notes with velocity and gate.

INFO

Needs clock (internal or external). Unlike most devices, Step Seq opens a custom step grid instead of a plain parameter list.

Editing the grid ​

Step Seq opens a full-width step grid (not the usual parameter list). An open-left title shows the Step Seq icon and R#/STEP SEQ (rack number, like other devices). Folder tabs SEQ and a pencil sit left of the BPM band (never the word SETTINGS). A small dim two-square mark between the tabs and the BPM is Select + Back. The gray header line continues under the BPM.

ControlSEQ (grid)Pencil (device settings)
EncoderMove focus across stepsMove between settings rows
SelectToggle the focused step ActiveLatch sticky edit on the focused settings row (same as other parameter lists)
Hold Select + encoderNudge Note; does not open a menu. After 200 ms the header shows a circle and squareHold-edit the focused settings row (that release does not stay latched)
Select + BackSwitch to the pencilSwitch back to SEQ
Long-press SelectThe header Select square fills while you hold, then a left list titled STEP 05 (1-based) opens with that step’s fields and values. Short Select on a list row latches sticky edit; it does not toggle ActiveOpen Options for the focused settings row
BackLeave Step SeqLeave Step Seq (does not return to SEQ). While sticky, Back restores the value first

Filled steps show a short velocity bar under the note name. It is a simple centered indication: visible from velocity 1, hidden at 0. Turning velocity grows the bar evenly from the middle. A 2-pixel-thick square playhead sits just inside the cell border. Pads sit on the left of the screen. Neighboring pads share one line. Hovering a disabled step stays dimmer than hovering an active one. Idle steps use the same dim gray for the name and the frame. Each pad shows the note name in the cell.

With a STEP list open on the left, Back closes it and stays on SEQ (and restores the field if you were in sticky edit). Select + Back still switches SEQ / pencil. Long-press Select on a STEP-list row opens that row’s Options on the right. There is no PARAMS header tab and no in-grid pencil.

Settings parameters ​

ParameterRangeWhat it does
Bypass0 – 1When on, the device is disabled and MIDI passes through unchanged.
Steps4 – 16Number of steps in the pattern (4–16).
Rate0 – 6Clock division for each step advance.
Seq Ch0 – 16Default MIDI channel for note output (Global follows the project global channel).
Direction0 – 2How the playhead walks the step ring: forward, reverse, or ping-pong.
Randomize0 – 1Momentary action — randomizes active steps using Rand Depth.
Rand Depth0 – 100How aggressively Randomize rewrites step fields (0–100%).

Per-step parameters ​

These fields are per step (not in the settings list). Long-press Select on a focused step — the header Select square fills while you hold — to open them on the left. Each row shows its live value. Tap Select to latch sticky edit, or hold Select and turn. Short Select on the grid still toggles Active. LFO, knob-macro, and external mappings can target a step field with that step’s index.

ParameterRangeWhat it does
Active0 – 1Whether the step fires when the playhead lands on it.
Note0 – 127MIDI note number for this step.
Velocity1 – 127Note-on velocity (also drawn as the short bar under the note name).
Gate10 – 200Note length as a percentage of the step.
Channel0 – 16Per-step channel override (Global uses Seq Ch).
Probability0 – 100Chance the step fires when active (0–100%).

TIP

Steps, Rate, Seq Ch, Direction, and Randomize live on the pencil tab (Select + Back from SEQ).
