Filter

General note/CC filter

When to use it ​

Place Filter when you need a message-type gate — pass only note on/off, CC, clock, or sysex while blocking everything else.

Parameters ​

ParameterRangeWhat it does
Bypass0 – 1When on, the device is disabled and MIDI passes through unchanged.
Note Off0 – 1Pass or block Note Off messages.
Note On0 – 1Pass or block Note On messages.
Control Change0 – 1Pass or block Control Change messages.
Program Change0 – 1Pass or block Program Change messages.
Poly Aftertouch0 – 1Pass or block After Touch Poly messages.
Channel Pressure0 – 1Pass or block After Touch Channel messages.
Pitch Bend0 – 1Pass or block Pitch Bend messages.
Clock0 – 1Pass or block Clock messages.
Tick0 – 1Pass or block Tick messages.
Start0 – 1Pass or block Start messages.
Continue0 – 1Pass or block Continue messages.
Stop0 – 1Pass or block Stop messages.
MIDI Timecode0 – 1Pass or block Time Code Quarter Frame messages.
Song Position0 – 1Pass or block Song Position messages.
Song Select0 – 1Pass or block Song Select messages.
Tune Request0 – 1Pass or block Tune Request messages.
SysEx0 – 1Pass or block System Exclusive messages.
SysEx End0 – 1Pass or block System Exclusive End messages.
Active Sensing0 – 1Pass or block Active Sensing messages.
Reset0 – 1Pass or block System Reset messages.
