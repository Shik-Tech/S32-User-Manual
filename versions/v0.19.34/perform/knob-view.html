Perform View ​

The Perform View is the home screen after power-on. It shows the selected knob, its macros, live macro indicator bars, and the tempo in the header. If the knob has one, two, or three macros turned on, Perform packs those macros — see One, two, or three macros.

Header ​

The top strip always shows where you are on the panel — read it left to right (numbered 1–3 on the screenshot). A line under the header separates it from the macros.

Macro rows ​

Four rows — one per macro. Each row is a live readout of what that macro is doing while you turn the knob (mode, target, current level). The exact labels depend on how the macro is configured — CC rows look different from device or LFO rows.

For a full explanation of each row type, see Macro rows on Perform — Classic MIDI, Device parameter, LFO parameter, CV16 control.

Hold Select (long press) Long-press Select to enter edit mode and change macros.

One, two, or three macros ​

When fewer than four macros are on, Perform packs them — empty + rows stay hidden until edit mode. The pieces stay the same as the four-row list: identity, live value, indicator bar, and LFO box. They just get more height. Row types (CC, device, LFO) are unchanged — see Macro rows on Perform.

One macro ​

The name and live value sit large on the first line. Channel, outputs, and the indicator bar sit on a second line below. POLY AT writes POLY AT in that large name, with the note next to the channel — see Classic MIDI.

If an LFO is assigned, L1 and a live wave appear beside the bar on that second line.

Two macros ​

Two taller rows with a dim line between them. Each row keeps the same split: name and value on the upper line; details, LFO, and bar on the lower line.

Three macros ​

Three compact rows — same columns as the four-row list, just taller. The live value is flush right, the bar sits to its left, and an LFO assignment shows a ~ badge next to the bar.

Four macros (or none) keep the usual four-row layout. Press Select (short) Select still opens edit mode with all four slots so you can add another.

Snapshot and morph knobs ​

A knob mapped to a snapshot slot or a morph amount is a scene control, not a device control, and Perform labels it that way at every size.

SNAPSHOT knobs show the bank they recall from — Knobs, LFOs, or the rack’s name — and the scene they are parked on. When that rack has a name, its number (01–08) sits dim to the left of the name. That scene name sits on the right, like any other macro value, with its number dimmer still, to the left of the name. A pad with no name shows 01–32 on the right. If nothing in the knob’s range is stored, the value reads --. On the macro grid, MODE reads SNAPSHOT, and MIN / MAX are snapshot numbers 1–32. Turning the knob lands only on snapshots that exist in that range.

MORPH knobs show the same bank, then which snapshot they are aiming at: TO DROP (or TO 04 if the pad has no name). The blend percent sits on the right; it reads 0% when that bank is not morphing. A morph knob picks up: until you turn it to that percent, the percent is dim and a dotted line on the bar marks where to catch. With one macro, the bank and that destination each get a line under the title. With two or more, they share the row. A is the live sound, not a stored pad — there is no A/B letter pair.

With two macros on, each row still reads SNAPSHOT or MORPH, then the full bank (Knobs, LFOs, or the rack name) and, on a morph row, TO plus the destination. The percent stays on the right. When the rack has a name, 01–08 sits dim to the left of that name. A rack with no name reads RACK 1–RACK 8.

Three and four macros use that same wording on the compact row. The scene name or percent stays on the right, in line with the other macro values.

The indicator bar still tracks the knob itself, so you can see where you are in the sweep. An LFO cannot be assigned to a snapshot or morph knob, so these rows never show an L box or a ~ badge.

Macro indicator bars ​

The indicator bars show the same value as the number, scaled to each macro’s min/max range. On four-row and three-macro layouts they sit just left of the value. On one- and two-macro layouts they sit on the lower line of the row, flush right.

Turn the knob to move all value lines together. LFO lines animate with the assigned LFOs during performance.

Pickup mode ​

Pickup mode (soft takeover) stops a macro from jumping to a new value the first time you touch a knob after loading a project or recalling a snapshot. Turn it on per macro in the macro grid — see Setting up macros — Pickup mode.

When pickup is waiting for you to catch up:

  • The macro value is dimmer on the row.
  • The indicator bar always keeps the solid value line on the physical knob (dim while you catch up, including when an LFO is assigned to that macro). A brighter dotted line marks the catch-up point — the last actual value, including a snapshot morph as it moves. You can still catch when that LFO is assigned and a snapshot morph is not moving. An assigned LFO follows that dotted catch (the macro is the offset of the LFO on the CC) until you catch up. When the LFO sits on the catch, that LFO mark is dotted too.
  • The knob does not send MIDI until you turn it to that line — then control resumes normally.

If the physical knob already matches the stored value when the project loads, pickup does nothing — you can play immediately.

Hold Select (long press) Long-press Select on Perform to enter edit mode and change macros, the knob name, or BPM.

Navigation ​

Perform is the home zoom level. The four levels are:

Grid ↔ Perform ↔ Macro selection ↔ Macro edit

ControlAction
Turn a panel knobJump to that knob on screen and send macro MIDI (when configured)
Press Back (short) BackOpen the Knobs Grid name list. Back on the Grid returns to Perform
Hold Select (long press) Long-press SelectThe header Select square fills; edit mode opens when the hold completes (edit mode). Letting go early stays on Perform. Select + Back during that hold still opens Main Menu
Hold Back and Select together Hold Select + BackOpen Main Menu (also from Knobs Grid; not while Knob Snapshots is open)
Turn the encoder EncoderDoes not open the names grid and does not walk knobs. Pick a pot by name on the Grid (Back, then encoder, then Select).

Knobs are numbered down each column: 1–4, 5–8, … 29–32. The left half of the panel and mini-grid is knobs 1–16; the right half is 17–32.

Panel knobs vs Knobs Grid ​

Two ways to change which knob Perform shows:

InputWhat happens
Turn a panel knobThe display jumps to that knob immediately. Macro MIDI is sent when configured.
Knobs GridPress Back (short) Back opens the name list. Encoder highlights a knob without moving the physical control. Press Select (short) Select confirms it and returns to Perform. Another Back returns to Perform (does not open snapshots).

Use the Grid when you want to look ahead — for example, check knob 12’s macros while leaving the physical knob where it is. Turn the actual knob when you want to perform and send MIDI.

INFO

If you move more than one knob at once, the display stays on the first knob that moved until it stops; other knobs still send MIDI, but the screen does not jump between them.

Knobs Grid overlay ​

Press Back (short) Press Back on Perform to open the Knobs Grid — a full-screen list of all 32 knob names in one 4×8 grid. The header map stays visible: a checker of short bars, and the current knob white. On this screen the map sits in an open tab.

While the grid is open, only the header mini-grid, page arrows, and BPM stay visible — no macro rows or bars behind the name list. Navigation and leaving: Knobs Grid. Back on the Knobs Grid returns to Perform. Hold Select+Back on the Knobs Grid opens Main Menu (it does not open snapshots). Open knob snapshots from Main Menu → Snapshots.

Edit mode ​

Hold Select (long press) Long-press Select on a knob to edit its four macros, knob name, and BPM.

INFO

See Edit Mode for the full walkthrough and Tap Tempo for setting BPM by tapping.

Macros ​

Each knob has four macros. Configure them in edit mode — see Macros.
