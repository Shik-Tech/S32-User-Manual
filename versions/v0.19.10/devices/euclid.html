Euclid

Euclidean rhythm generator

When to use it ​

Add Euclid after Clock for polyrhythmic Euclidean grids. Up to four layers can run in parallel with independent step counts, pulses, and rates.

INFO

Needs clock (internal or external). Euclid opens a two-tab device like Step Seq — not a long flat parameter list.

GRID and pencil ​

Euclid opens a full-width GRID of four layer rows. An open-left title shows the Euclid icon and R#/EUCLID. Folder tabs GRID and a pencil sit left of the BPM band. A small dim two-square mark between the tabs and the BPM is Select + Back.

ControlGRID (layers)Pencil (device settings)
EncoderMove focus across the four layer rows (including disabled layers)Move between settings rows
SelectDoes not enable or disable the layer. Use Enabled on the LAYER listLatch sticky edit on Bypass. Tap Select again to keep the value; Back restores it and leaves Euclid
Hold Select + encoderNudge that layer’s Note on a continuous row; does not open a menu. After 200 ms the header shows a circle and squareHold-edit Bypass (that hold does not latch sticky; same circle-and-square cue)
Select + BackSwitch to the pencilSwitch back to GRID
Long-press SelectThe header Select square fills while you hold, then a left list titled LAYER 1 (1-based) opens with that layer’s nine parametersOpen Options for Bypass
BackLeave EuclidLeave Euclid (does not return to GRID)

Each layer is a strip of Step Seq pads that fills the row, even when that layer has only a few steps. Pulse steps are active pads; the rest are idle pads. Pads do not brighten for hover — the focused layer is marked with four corner ticks only. Pads do not show the layer note or a velocity bar. A 2-pixel-thick square playhead sits just inside the current step. Neighboring pads share one line so idle frames stay clean. Hold Select to change the note: the row keeps its outer box, inner walls and the playhead go away, and the note sits in the middle. Turn the encoder to change it; release Select to restore the grid. Disabled layers stay on screen and look dim. Enable or disable a layer from Enabled on its LAYER list.

With a LAYER list open on the left, tap Select on a value to latch sticky edit (same as Step Seq STEP). Tap Select again to keep the value and stay on the list. Back restores the value from when you entered and closes the list. Select + Back still switches GRID / pencil. Long-press Select on a LAYER-list row opens that row’s Options on the right.

Choosing a layer from Options ​

Long-press Select on the pencil or on a LAYER-list row for Options. LAYER is the last row and opens a four-tile chooser:

ControlDoes
Turn the encoder EncoderMove between LAYER 1 – 4
Press Select (short) SelectOpen that layer’s left parameter list
Press Back (short) BackKeep the current layer

The first rows of that Options menu are the same ones every device has, so giving a Euclid parameter an LFO or a mapping works exactly as it does elsewhere.

ParameterRangeWhat it does

Per-layer parameters ​

These nine fields belong to the focused layer. Long-press Select on a layer in GRID to open them on the left.

ParameterRangeWhat it does
Enabled0 – 1Turn this Euclidean layer on or off from the LAYER list.
Steps1 – 16Number of steps in the rhythm ring.
Pulses1 – 16Number of hits distributed across the steps.
Rate0 – 6Clock division for this layer.
Shift0 – 15Rotate the pattern within the ring.
Note0 – 127MIDI note emitted by hits on this layer (hold Select on GRID to see it on the row).
Channel1 – 16MIDI channel for this layer’s output.
Velocity1 – 127Note velocity for this layer.
Gate0 – 200Note length as percent of the step.
