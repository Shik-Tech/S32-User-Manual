Projects & Snapshots ​

Project ​

A project holds everything about one performance setup:

  • 32 knobs and all macro mappings
  • Up to 8 racks (MIDI device chains)
  • 16 LFO configurations and assignments
  • Snapshots for scene recall within the project
  • Clock source and BPM, default MIDI channel, and encoder-button shortcut

Use Main Menu → Project → Library to create, load, rename, or delete projects. Clock, channel, and encoder live under Project Settings. See Project for save and list workflows.

Note names (Middle C as C3 or C4), MIDI Thru, contrast, firmware, and bulk migrate stay on this S32 under Settings.

Typical workflow:

  1. Create or load a project from Main Menu → Project → Library.
  2. Set clock, channel, and encoder under Project Settings.
  3. Build racks, macros, and LFO routing.
  4. Save Project when you want changes to survive power-off.
  5. Use Save As on the Library side menu to fork a copy under a new name.

Switching projects with unsaved edits may prompt you to save or discard. Loading a project applies its clock and channel and stops transport.

Snapshot ​

A knob snapshot captures the 32 pot positions in the active project for instant recall during a set. Open the slot grid from Main Menu → Snapshots after picking Knobs — see Knob snapshots. New slots are named S1…S32 from the slot number.

A rack snapshot captures device parameters (and the Step Seq pattern) for the highlighted rack. Open it from the rack-list side menu — see Rack snapshots.

An LFO snapshot captures all 16 S32 LFO configs (and CV16 configs when present). It does not store assignment wiring. Open it from the LFO-grid Options menu — see LFO snapshots.

Arrange is a 16-row song grid of already stored snapshots across Knobs, LFOs, and racks. When the playhead lands on a row it recalls occupied cells as a scene; rest (--) skips that bank. Open ARRANGE from Main Menu (first item) — see Arrange.

Morph glides from the live sound to an occupied pad (this bank's FADE TIME; Arrange playhead uses Arrange FADE TIME). Another occupied pad retargets. See Morph.

Use snapshots when:

  • You need fast scene changes (intro / drop / outro) within one project.
  • You want to experiment, then jump back to a known point.

Use Save Project when:

  • You changed structure (new devices, macro modes, LFO wiring) or Project Settings and want it after power off.

TIP

Live take and recall live on Main Menu → Snapshots (the BANK pad) and on the rack / LFO side menus.

TIP

  1. Build and Save Project once per song or set.
  2. Use snapshots for sections within that set.
  3. Save As on the Library to fork a variation under another name.
