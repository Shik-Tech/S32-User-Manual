SysEx on Perform ​

SysEx macros send a custom MIDI System Exclusive message from the knob. On Perform they show SYX plus the message length — no controller numbers, no channel.

What to expect on the row ​

Part of rowSysEx macro
Message typeSYX
Message length6 BYTES — how many bytes the knob sends (0–16)
OutputsU / 1 / 2
Live value14-bit level mapped into the message bytes

The length is the same number the SysEx macro grid shows. An empty message reads 0 BYTES and sends nothing.

With one macro on, SYX is large and the length sits on the lower line.

With two macros on, each row keeps the mode name on the upper line and the length (plus outputs) on the lower line.

Name a SysEx control ​

Like other classic MIDI macros, a SysEx macro can have a custom name. When set, the name replaces SYX and the length on dense rows; on packed 1- and 2-macro views the whisper reads SYX 6 BYTES after the name. There is still no channel.

Build your message in edit mode with the SysEx macro grid and SysEx editor.
