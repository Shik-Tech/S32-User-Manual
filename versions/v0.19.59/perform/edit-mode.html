Edit Mode ​

Edit mode is the Macro selection zoom level: it configures the selected knob — knob name, BPM, and four macros.

Zoom stack: Grid ↔ Perform ↔ Macro selection (this page) ↔ Macro edit.

Enter edit mode ​

  1. On Perform, turn a panel knob to show the knob you want — or Press Back (short) Back to open the Knobs Grid, highlight a name, and Press Select (short) Select to confirm.
  2. Hold Select (long press) Long-press Select (~700 ms). The header Select square fills while you hold. Edit starts as soon as that hold is long enough, while Select is still down, unless you pressed Back. Letting go early clears the square and stays on Perform.

Short Select on Perform does not enter edit. Select + Back still opens Main Menu during that hold and does not enter edit.

The encoder on Perform does not pick a knob. Encoder browsing of names happens on the Grid.

Macro rows 0–3 appear on the left with four-corner marks around the whole row (through the indicator bar and the value) — even if Perform was showing the packed one / two / three macro layout. What each row displays depends on its macro mode — see Macro rows on Perform. Empty / Disabled rows show a centered +; when selected they read + ADD MACRO with the plus in the same place.

Macro indicator bars on the right mirror each row (value and LFO modulation lines).

The header still shows the knob name and BPM. Rename the project from Main Menu → Project.

Select a field ​

Edit mode opens on macro row 0. Encoder order is knob name → BPM → macros 0–3 (no wrapping). From the first macro, one step up is BPM; two steps up is the knob name.

Macro row selected ​

Press Select (short) Press Select again to open the macro mode grid (CC, device param, LFO, etc.). Press Back (short) Back from that grid returns here (Macro selection), not all the way to Perform. Leaving a MIDI message mode for Disabled, Device Parameter, S32 LFO, CV16 LFO, or CV16 CTRL removes an assigned LFO. Switching among MIDI message modes keeps it.

Empty macro selected ​

A Disabled (empty) row selected in edit mode shows + ADD MACRO. Press Select (short) Press Select to open the macro grid and choose a mode.

Macro Options ​

Hold Select (long press) Long-press Select on a macro row (not Select + Back) opens Macro N - Options. The list matches device and LFO parameter Options as far as a macro can:
RowWhat it does
ModulationNested menu when an LFO is assigned: Range first (a folder with Range Min / Range Max for the modulation window), then Re-Assign LFO, Edit LFO, Enable/Disable LFO, and Remove LFO. With no assignment it is Assign LFO only. An S32 LFO or CV16 LFO macro is already the LFO — that submenu is Range / Edit / Enable-Disable.
MIDI Learn / Name Macro / Edit the Device / Edit MessageStay on this root list. A Disabled row offers MIDI Learn and IN SNAPSHOT.
IN SNAPSHOT ON/OFFThis macro’s live switch. It starts ON and stays on the list even when no knobs snapshot is occupied. OFF leaves the macro where it is on every recall, fade, and morph. A SNAPSHOT or MORPH macro does not show this row. Change its mode, or map another parameter to it, and the row comes back ON. See Snapshots.

There are no divider lines between groups. Back from Modulation returns to this list.

Knob name ​

When the encoder is on the knob name, four-corner marks wrap the name at the length on screen — not the number. The number drops with the name. Press Select (short) Press Select to open the text editor.

BPM field ​

Hold Select (long press) Turn the encoder Hold Select and turn the encoder to nudge ±1 BPM (internal clock only).
