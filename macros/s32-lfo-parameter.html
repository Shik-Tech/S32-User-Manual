S32 LFO Parameter ​

Sets a setting of one of the project's LFOs.

When to use it ​

Play an LFO: speed it up, deepen it, change its shape. The knob changes the LFO's own setting. SAVE PROJECT keeps it, and a morph back to 0% returns to it.

Settings ​

SettingRangeWhat it does
LFO INDEXLFO 1 – 16The LFO the knob sets.
CV PARAM.LFO settingThe setting the knob changes. See the table below.
MINIMUM / MAXIMUMThe setting's rangeIn the setting's own units: note values or Hz, %, degrees.

Also INVERT and PICKUP: see Settings most modes share.

What the knob can set ​

Pick it with CV PARAM.:

CV PARAM.What it does
ENABLEDTurns the LFO on or off.
WAVETABLEThe wave shape.
RATEHow fast it runs: a note value with SYNC on, Hz with it off.
SYNCFollows the clock, or runs free.
DEPTHHow far it moves its targets.
OFFSETShifts the whole wave up or down.
PHASEWhere in the wave it starts.
